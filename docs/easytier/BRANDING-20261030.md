# Clash Easytier 名称和图标验收

- 应用名称：`Clash Easytier`，Android 11 和 Android 17 两个预览包一致。
- 图标：使用用户提供的 PNG 原字节，SHA-256 为 `7de47ecc24bc7c9b869a3bc04ab6cc795dfca90bea87d0ffbfb493b54c57964e`。
- 启动图标同时覆盖普通、圆形、adaptive 和旧密度回退资源。原图通过 XML 安全区缩放显示，没有重新绘制或裁剪原文件。
- 未来原生构建由 `nativeMeshHarness=true` 启用品牌资源覆盖；普通上游构建不受影响。

## 本轮实际检查

两份新 APK 均通过 Android aapt 名称检查、zipalign 16 KiB 对齐检查及 apksigner 签名校验。每份 APK 的 27 个 DEX、12 个原生库、AndroidManifest.xml、assets 和其余非资源文件均与对应真机基线逐字节一致。非品牌资源文件恢复原始编译字节，既有资源 ID 和非品牌资源值保持一致；资源编译器的 PUBLIC 元数据和文件路径布局存在变化。

安装器已有回归测试 22/22 通过。品牌资源使用固定 Apktool 3.0.3 构建，工具 JAR SHA-256：`dbf930b076c6b9be08d57c449cacefc3bdd6b71ebd59b3066fc0e1f5b14f9423`。合并脚本在未知资源变化时停止，不重新编译或替换网络代码。

Android 11 真机首次安装被 MIUI 拒绝，返回 `INSTALL_FAILED_USER_RESTRICTED`。用户随后明确允许，第二次安装成功；实际查看系统“应用信息”截图，已确认名称为 `Clash Easytier`、图标与指定图片一致且完整显示。新预览包保留在该手机上，没有启动 VPN 或导入配置，也没有绕过 USB 安装限制。Android 17 本轮未重新连接验收。

本轮未重新执行组网测试。原双真机网络结果属于原 APK；新包只继承经过摘要核验的相同执行代码，不将新的 APK 摘要标为已经完成历史真机测试。原有兼容范围和未完成事项见 [双真机说明](TWO-DEVICE-PREVIEW.md)。

## 签名与回退

新包使用本机保存的独立签名密钥；私钥和 DPAPI 保护的密码仅当前 Windows 用户可读，不上传仓库或放入交付 ZIP。新签名与旧 CI 调试签名不同，旧原型不能直接覆盖安装。需保留资料时先自行导出，再决定是否卸载旧原型；安装器不会自动卸载、清数据或修改原版 CMFA/EasyTier。

旧双真机目录、旧 APK 及旧 ZIP 全部保留。回退可使用旧包；跨签名同样需要先保护原型资料。新交付仍是预览版，PR 保持 Draft。
